# CIT 240 – Open Source Programming
## Laboratory Activity 1: Open Source Project Information Viewer

### Project Overview
This repository contains a simple PHP and HTML web application developed for **CIT 240 – Open Source Programming (Laboratory Activity 1)**. The program displays structured metadata about an open-source project (the Python Programming Language), highlighting key details such as licensing, authorship, repository link, and versioning.

---

### Key Features
- **Simple HTML/PHP Interface**: Clean card layout styled with CSS.
- **Comprehensive Project Details**:
  - Project Name
  - Developer / Author
  - Programming Language
  - Open-Source License
  - Project Description
  - Official Repository URL
  - Latest Version & Platform Support
- **Git Version Control Integration**: Step-by-step repository tracking and incremental commit history.

### Usage & Instructions

#### How to Run
1. Open the project directory:
   ```bash
   cd CIT240_Lab01
   ```
2. Open `project_info.php` in any web browser or host it using a PHP web server:
   ```bash
   php -S localhost:8000
   ```
3. Navigate to `http://localhost:8000/project_info.php` in Chrome.
